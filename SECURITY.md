# Security Policy

## Secrets

Never commit secrets.

Do not commit:

- `.env`
- API keys
- database URLs
- private keys
- OAuth secrets
- service account credentials
- production tokens
- Supabase service role keys
- GitHub tokens

Use `.env.example` for required environment variables.

## Reporting security issues

For now, report security issues directly to the Mebbian founders.

Do not open public issues for vulnerabilities.

## Access policy

Access should follow operational need.

Org ownership is limited. Repository access is granted by team and role.
